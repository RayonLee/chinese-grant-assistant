# 论证、证据与自然中文

## 组织各部分

背景回答为什么有必要做、已有研究做到什么程度、哪些问题仍需回答；研究内容写具体做法；前期基础写能做的理由；预期成果写交付什么、怎样验收。不要在每栏完整重复整套研究方法。

提出困难要有材料支持。可以写“拟分析既有作业，确定学生常见困难”，不能没有依据就写“学生普遍只会复述案例”。研究设想、预期改善、已有成效使用不同表述。

创新点应落在实际改进：研究问题、材料组织、教学方法、评价或适用条件。使用某个模型、视频或平台本身不等于创新；未做全面检索，不写“首次”“填补国内外空白”。不为了论证完整编造学生人数、成绩提升、试点结果或制作资源。

## 国外经验怎样写

优先找到能回答关键问题的研究及原始实践说明，并说明与国内场景的关系。可以将一个例子写成“在哪门课/什么对象中采用什么做法，报告了什么结果或经验，本项目借鉴其中哪一环节”。

证据层次直接影响措辞：

- 系统综述、元分析：可作为总体研究依据，仍需核对对象、比较条件和结论范围。
- 实证研究：写明研究对象和条件，不把其效应量当作本项目的预计增幅。
- 课程案例或官方教学报道：可以说明存在的做法及实施经验，不能写成严格效果证明。
- 理论框架：用于解释和设计，不把理论预期当作本项目已发生的结果。
- 政策指南：支持规范或政策要求，不用于证明学习成绩改善。

资料数量由申报篇幅和证据需要决定，不固定“必须9篇”或固定外国文献比例。用户指出国外依据薄弱时，补检索能支持核心判断的原始研究，不只增加作者名字。国内研究和政策也要按课题实际需要纳入。

## 申请人基础怎样挖掘

按“已有事实—本人贡献—支持哪项本次任务”整理。尽量说明用途，少堆履历：

- 课程建设经验 → 教学重点、课堂组织、评价条件。
- 案例与教材 → 可用素材、概念依据、讨论问题。
- 已发表研究 → 方法、研究问题、可继承发现；只写已核实的相关部分。
- 真实资源与合作 → 能提供什么支持、已确认到何种程度。
- 论坛、公众号或既有交流渠道 → 素材更新、试用反馈与推广，不等于已经承诺使用的参与单位。

企业案例可支持商业场景，不能不加说明地当作政务案例的直接基础。多项成果的领域与本项目不相符时，写清可借用的能力，不夸大直接相关性。

## 文字风格

以评审能迅速读懂为准，保留必要的专业概念并在需要处解释。下列示例用于理解表达方向，不是机械替换词表：

| 容易写得晦涩的表述 | 更直接的表达 |
| --- | --- |
| 核实情境识别、概念应用与证据论证难点 | 分析以往作业，找出学生读懂案例、运用知识和说明理由时遇到的问题 |
| 以等量信息参照和迁移任务检验改进 | 用包含相同事实和知识的文字案例作比较，再用新案例检查学生能否运用所学 |
| 建立教学闭环与统一量规 | 写明课堂各环节，并按同一套评分标准评价作业 |
| 促进知识内化、实现多维赋能 | 写出学生应能完成的任务，以及需要哪项材料来判断 |
| 形成可推广的范式 | 总结适合哪些课程、怎样使用以及需要哪些条件 |

上述比较设计只适用于对应研究；不要因为换词就凭空增加比较组或新任务。自然中文不等于删去研究条件。个人还是小组作业、何时提交、材料是否相同等关键限定必须保留。

避免“技术赋能—路径重构—生态构建”式连续抽象名词。必要时把一个长句拆为“先做什么，再做什么，目的是检查什么”。短句也要保留逻辑和证据，不把正式申报书改成口号或聊天体。

## 引文核查与APA默认格式

维护一个轻量的文献记录：题录、原始网址或DOI、支持的具体判断、资料类型、核验范围。只有题名/摘要时明确限制。搜索结果、自动引文和DOI题录只用于定位；需要依赖具体结论时读原始来源相应部分。

APA默认检查：

1. 正文作者—年份与文末逐条对应，拼写和年份一致。三位及以上作者正文按APA规则用et al.；同一括号中多项按作者排序。
2. 文后按作者排序。核对作者顺序、题名、刊名、卷期、页码/文章编号和DOI。书籍核对版次，网页核对署名与发布日期，机构报告核对出版年。
3. 在线上线年、正式卷期年和版权年不一致时，以实际引用版本为准并在工作记录中注明，不为了与旧稿一致而随意改元数据。
4. 使用文章编号的期刊不编造页码；没有DOI就用可靠原始链接，不猜DOI。原文没有作者或日期时按所用引文规范处理，不补造。
5. 未能核实的文献不作为已核实依据。找不到可靠来源且不能从用户材料追溯的条目，不编入正式稿；确需保留的待核条目明确标识，按下述离线规则处理。
6. 用户只要APA文字参考文献时直接输出；需要Word时再处理斜体、悬挂缩进等。模板或指南明确规定版式则依其要求。

如当前环境提供citation-management，可按需要调用；它不是本技能的必装依赖。自动验证通过只能证明相应格式或链接检查通过，不能证明正文论断成立。

## 用户要求离线工作时

用户给出完整原文且出版信息可辨认时，可以直接据此核对，不为走流程再强制联网。只有题录或摘录时，依据已给内容写作，引用限于摘录能够支持的判断；可以在待核稿中保留按所给题录整理的条目，在正文外说明“题录据提供材料整理，尚未核对原始出版物”。不要把待核稿称为可直接提交的定稿，也不要因无法联网就把可追溯的引用全部删除。

文献记录分别标清“用户提供原文已核对”“仅据提供题录/摘录整理”“原始来源已检索核对”等实际状态。必要的提交前核查集中列出；用户另行授权联网后再补做，不反复索要已给出的许可。
