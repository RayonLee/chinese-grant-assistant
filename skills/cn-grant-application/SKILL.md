# 中文课题申报

把本次指南、用户最新稿和真实已有成果，整理成符合申报要求、论证充分、中文自然的申报材料。默认直接完成已授权工作，不在每个阶段反复请用户确认。

## 先确定本轮任务

- **新项目或整体重写**：执行下述完整流程，按正式申报表组织内容。
- **已有稿修改**：以用户明确指定的最新稿为基准，只修改本轮范围；整稿修改才做全篇复核。
- **只问方向、文献或用语**：直接回答对应问题，不自动重写或另存完整申报书。
- **只要 prompt、提纲或待审方案**：交付该项，遵守用户明确的“审后再执行”边界。后续已授权执行则继续，不重复索要许可。

## 默认写作规则

1. 用中国课题申报常见、直接的书面语。具体写清谁做什么、为什么做、怎么判断效果；不为显得学术而堆术语。语言示例见[写作与证据](references/evidence-and-writing.md)。
2. 尊重用户已改过的句子、删减和数据。先读现稿再修订，不把较早的机器稿当成最新版，不擅自恢复被删论文、人员或承诺。
3. 需要真实引用。默认APA第7版，正文作者—年份，文末统一参考文献；本次指南有指定格式时先按其要求，用户明确要求不同格式则说明冲突并按本轮指示处理。
4. 国外经验要说明具体做法、适用范围和本项目怎样借鉴；申请人基础要说明已有成果如何支持本次任务；工作计划要有明确时间、任务和阶段成果。
5. 除非用户要求原位修改，完整修订另存新版本，并附简短改动说明，保留原稿。

这些是写作原则，不是所有课题的固定研究设计。不要预设申请人、项目类别、周期、字数、团队、技术或成果数量；以当次材料和用户指示为准。新指南中的方向、年限、金额、引用格式和成果要求均需重读。

## 完整申报流程

### 1. 阅读指南和现有材料，确定方向

读取通知、指南、申报表、评审标准，以及已有申请、申请人简历和成果资料。按[指南与材料整理](references/intake-and-plan.md)建立简要要求表，记录条款来源和适用项目类别。先查现有文件和对话能否回答，再问真正缺失的信息；非关键空缺留待补项，继续其他工作。

用一句话说明“主要对应指南第几项、名称是什么、为什么符合”。区分主方向与辅助技术。对只有重点项目适用的条款，不直接套给一般项目。用户只问方向时，到这里即可。

### 2. 从材料形成论证，不先套通用长文

围绕“实际要解决什么问题—已有做法能支持什么—还有什么没解决—本项目如何开展—凭什么能做”组织内容。不要仅因拟使用AI、视频或案例就宣称创新。

读取[写作与证据](references/evidence-and-writing.md)，把研究背景、研究内容、预期成果和前期基础分开处理。将申请人的课程、案例、教材、论文、项目和资源逐项对应到本次任务；已有事实、未来安排、效果预期必须分清。

### 3. 找到并核实文献

按本项目的问题和机制检索相关国内外研究、权威政策及可借鉴实践；已有引用先检查。优先期刊、出版社、研究机构和官方原始来源。为重要论点核对正文相关部分，只有题录或摘要就记录读取范围，不宣称全文验证。

用户要求不联网时，依据所给原文或摘录继续完成可完成部分，明确哪些题录或判断仍待原始来源核对，不能以本流程要求检索为由自行联网。

区分元分析、实证研究、课程案例、教学报道、理论框架和政策指南。国外案例可以支持借鉴做法，不能直接证明本项目有效。无论使用文献工具或人工整理，均做正文引用与文后条目的一一核对；DOI成功解析不等于论点得到支持。具体规则见[写作与证据](references/evidence-and-writing.md)。

### 4. 把研究内容变成可执行计划

依本次周期列出“时间—任务—阶段成果”的计划表，有真实分工才填负责人。教改课题若涉及授课，再列“学期/月份—学期周次—教学内容—产出”的课程表；与总表对应。课程表不是所有课题必备栏目。

按[指南与材料整理](references/intake-and-plan.md)核对准备、实施、评价、修改、结项的先后关系。目标数量、成果数量、时间和现有资源一致；没有实测数据，不承诺虚构提升比例。比较教学效果时，只在确有必要且可实施的情况下安排比较组、个人作业和后续任务，不把本次试写的方法强加给所有研究。

### 5. 按模板成稿并完成复核

按学校或资助方的栏目、字数和格式填写，不能套国自然三年长篇或外国基金结构。处理Word/PDF时，使用当前环境可用的相应文档技能或工具，保留模板和签章区域；不依赖本技能开发时的电脑路径。没有可用的文档渲染工具时，如实交付可编辑内容并说明未完成视觉检查，不谎报Word完成。

交付前读取[复核与交付](references/review-and-delivery.md)。有字数上限时可运行自带的[scripts/check_sections.py](scripts/check_sections.py)做保守字符检查；官方计数口径优先。修订后的实际文档也要核对，不能只检查未写入的中间稿。

默认交付用户要求格式的申报稿；已有稿实质修订时再附简短的修改与取舍说明。关键待补信息单列，不混进看似已确认的正文。若用户只要正文，不额外交付一套过程文件。

## 使用边界与复用

本技能独立包含核心流程，无需每次安装或读取五个上游技能。来源和取舍说明见[来源说明](references/sources-and-adaptation.md)，仅在维护、溯源或用户询问时读取。

内部比对和文献核验属于写作工作；提交申报、发邮件、替人签名、作出人员或单位承诺须有对应授权。不要把材料上传到外部服务以“自动优化”；公开文献查询只需发送公开题名、关键词或DOI。
